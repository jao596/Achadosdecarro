⚙️ Configuração do repositório (fazer 1 vez)

Esse token fica salvo só neste navegador (nunca é enviado para lugar nenhum além do GitHub).

  1. Acesse github.com → foto de perfil → Settings → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Clique em "Generate new token".
  3. Em "Repository access", escolha "Only select repositories" e selecione este repositório.
  4. Em "Permissions" → "Contents", selecione "Read and write".
  5. Gere o token e cole aqui.
